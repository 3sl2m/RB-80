# РБ-80 — интерактивный симулятор

В папке находится готовый сайт. Главная страница — index.html.
Все изображения, плакаты, геометрия и код встроены в этот файл. Сборка и установка библиотек не нужны.
Архив подготовлен локально; сам сайт ещё нигде не опубликован.

## GitHub Pages

1. Создайте на GitHub публичный репозиторий, например rb80. Для такого варианта подходит GitHub Free.
2. Распакуйте архив и загрузите index.html и .nojekyll в корень репозитория. README.md можно загрузить вместе с ними.
3. Откройте Settings → Pages → Build and deployment → Source → Deploy from a branch.
4. Выберите main и /(root), затем Save.
5. Адрес сайта появится в разделе Pages. Для репозитория rb80 обычный адрес — https://ВАШ-ЛОГИН.github.io/rb80/.

Для обновления замените index.html новой версией в том же репозитории.

Официальные инструкции: [Создание сайта GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [Выбор источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Netlify

Распакуйте архив в отдельную папку и загрузите эту папку через Netlify Drop. Внутри неё index.html должен лежать непосредственно в корне.

Официальная инструкция: [Ручная публикация в Netlify](https://docs.netlify.com/deploy/create-deploys/#drag-and-drop).

## Локальное использование

Откройте index.html в современном Chrome или Edge. После скачивания файл работает без интернета.

Во вкладке «Модель» ползунок «Подсветка тёмных мест» регулирует мягкий заполняющий свет. Начальная величина — 60%.
Механика и измерительные пороги симулятора остаются демонстрационными; справочные подписи плакатов отделены от результатов ручного калькулятора.
